Proposed run limits

300-second overall deadline; 45 seconds per call. Request at most 2,048 output tokens per call and 65,536 output tokens in total. Every root, helper, continuation, review, retry, and synthesis shares these limits. Input charges are separate.

At most one retry per step after an explicit rejection before generation, within every remaining limit. Ambiguous timeouts are not automatically retried.

These are proposed live defaults. The fast demo timers do not measure actual provider performance or enforce a monetary budget.

What does the team check?

Each root drafts before seeing its peers. Each then reviews other available root drafts once. Helpers support their parent; their output is not another independent vote. With one root draft, peer review is skipped.

Multiple agents may use the same provider and profile. Separate drafts do not imply independent errors. Sources stay unverified unless separately retrieved and checked.

Provider setup

This is an interactive design. All three providers are in Demo mode; no connection has been checked.

  • The first live version will read your own OpenAI, Anthropic, and Gemini keys from server environment variables.
  • Keys stay out of browser storage, chat exports, and ordinary logs.
  • Selected providers receive relevant conversation context. During review, they also receive the other agents’ drafts.
